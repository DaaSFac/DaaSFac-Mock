## What this repository is

The product pages on [daasfactory.live](https://daasfactory.live) show live
charts and a live table so a visitor can see what a DaaSFac pack actually looks
like before obtaining one. Those pages need data to render. This repository is
that data: a small, reduced sample, published here only so the front end has
something public to load.

It exists to **show** the shape of a pack. It is not a free tier, not a preview
edition, and not a smaller version of the product you are welcome to keep.

## What to use instead

You almost certainly want one of the real packs, and both are easier to work
with than this one:

| | **Open Source packs** | **Community OS packs** |
|---|---|---|
| Licence | CC BY 4.0 | AGPL-3.0-or-later, or commercial |
| Cost | free | free key, or paid commercial licence |
| Repository | fully public | private, key-gated |
| Key needed | no | yes — claim it from your DaaSFac portal |
| What you owe | visible attribution | publish your source, or buy the commercial licence |
| Complete data | yes | yes |

Both are complete, both are supported, and both are properly licensed for reuse.
This mock is neither.
